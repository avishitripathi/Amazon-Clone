# Amazon Clone

Amazon Clone is a responsive e-commerce homepage inspired by the design and layout of Amazon. Built using HTML5 and CSS3, this project focuses on recreating a modern online shopping interface while applying frontend development principles. It helped strengthen my understanding of webpage structure, CSS Flexbox, responsive design techniques, and user interface development by replicating the look and feel of a real-world e-commerce platform.

## ✨ Features

* Responsive homepage layout
* Amazon-inspired navigation bar
* Search bar and category section
* Product showcase cards
* Footer with multiple information sections
* Clean and responsive design

## 🛠️ Tech Stack

* HTML5
* CSS3

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/avishitripathi/Amazon-Clone.git
```

2. Open `index.html` in your preferred web browser.
